# Matematika felvételi feladatsorok – 9. évfolyam

Egyszerű statikus oldal a 9. évfolyamos központi matematika felvételi feladatsorokhoz (2005–2026). Minden évhez és vizsganapohoz linkek a feladatlapra és a javítókulcsra, az eredeti oktatas.hu PDF-ekre mutatva.

A PDF-ek nincsenek a repóban. Szerzői jogi védelem alatt állnak, a jogtulajdonos az Oktatási Hivatal.

Megnyitás: `index.html` böngészőben, vagy GitHub Pages-en.
